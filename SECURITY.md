# Security Policy

## Supported versions

Security fixes go into the `main` branch only. The skill has no releases, so update your clone with `git pull`.

## Reporting a vulnerability

Do not open a public issue. Report privately through GitHub:
https://github.com/byrodi/humanizer/security/advisories/new

Include the commit you use, steps to reproduce and the impact you expect. A prompt injection that makes the skill act on instructions inside the edited text counts as a vulnerability. Reports are acknowledged within 14 days. A confirmed vulnerability is fixed on `main` and disclosed through a GitHub Security Advisory, normally within 90 days of the report.
